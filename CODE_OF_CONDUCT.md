# Contributor Covenant Code of Conduct

BMEC contributors, maintainers, and participants are expected to make project
spaces welcoming and respectful. This code applies to issues, pull requests,
reviews, discussions, and project events.

## Expected behavior

- Be considerate, patient, and constructive.
- Discuss technical work in good faith and focus criticism on ideas and
  behavior rather than people.
- Respect differing backgrounds, experience levels, and communication styles.
- Accept responsibility for mistakes and help repair their impact.
- Keep private information and security reports in appropriate private
  channels.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, unwanted sexual
attention, doxxing, publication of private information, and deliberate
disruption of project spaces are not acceptable.

## Reporting and enforcement

Report a concern privately to the project maintainers through GitHub. Do not
include public issue details when they would identify or endanger a person.
Maintainers will review reports, protect reporter confidentiality where
possible, and take proportionate action, including a warning, removal of
content, temporary limits, or exclusion from project spaces. Maintainers who
are part of a report should not decide its outcome alone.

This code is based on the Contributor Covenant, version 2.1. For the full
upstream text and interpretation guide, see
[contributor-covenant.org](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
