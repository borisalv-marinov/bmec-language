# BMEC roadmap

BMEC 0.9.1-beta.3 is a prerelease for developer evaluation. This roadmap
describes direction, not a schedule or promise.

## Current focus

- Make clean installation and first-app learning reliable.
- Publish compiler-backed language knowledge for both people and AI agents.
- Keep security, platform support, and target limitations tied to tested
  implementation and evidence.
- Validate the website, package, and editor as a coordinated release.

## Later work

- Improve editor and diagnostics workflows where developer feedback shows a
  concrete need.
- Expand application and platform evidence without implying universal
  backend parity.
- Revisit language and package compatibility only through a separately
  reviewed release plan.

There are no promised delivery dates. This beta adds no language feature
programme; future work should be driven by specific user needs and verified
defects.
