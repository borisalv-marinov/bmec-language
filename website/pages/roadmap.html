BMEC is a developer preview under active development.

The current work focuses on making BMEC easier to discover, learn, build with, and operate. The public site tracks capabilities from compiler metadata and checked examples so its support notes can stay specific.

Available now

Typed language and CLI, editor support, generated UI, database adapters, authentication, PostgreSQL migrations, AI discovery, browser playground, and local container deployment.

Still in progress

Broader platform validation, independent external review, and release preparation. Check the package and capability notes before choosing BMEC for a production system.

This is a product status summary, not a schedule or delivery promise.
