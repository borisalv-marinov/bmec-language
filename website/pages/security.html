Make trust boundaries explicit.

BMEC provides server-side authentication and role checks, origin validation for unsafe production requests, bounded request sizes, rate limiting, and explicit host capabilities. Application code still needs correct policies and careful secret handling.

  • Keep secrets on the server and out of browser bundles.
  • Use exact trusted origins behind a configured TLS proxy.
  • Give database and filesystem capabilities only where needed.
  • Review migrations and backups before changing production data.

BMEC remains a developer preview. A passing repository scan or local deployment smoke is not an independent security audit.
