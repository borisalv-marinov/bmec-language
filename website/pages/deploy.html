Run BMEC beside the database you control.

The reference deployment uses Linux containers and PostgreSQL. It keeps credentials in mounted secret files, binds the app to a chosen host interface, and exposes liveness and database readiness checks.

  • Use a trusted TLS reverse proxy for browser traffic.
  • Keep the database port private.
  • Back up PostgreSQL before schema upgrades.
  • Verify the restored schema and application data before switching traffic.
