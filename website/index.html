Architecture and trust

Know what BMEC checks—and what your host owns.

Authentication is separate from row authorization. Origin rules protect browser writes, but TLS and proxy identity belong to the host. The database adapter does not add ownership predicates on your behalf.

Compiler architectureSecurity limitsThreat modelDeployment requirementsCapability coverage

Validation boundaries

  • Windows and Linux have local candidate checks.
  • macOS is not validated.
  • No independent security audit or production certification is claimed.
  • Native compilation supports a documented subset.
