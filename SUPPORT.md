# Support and troubleshooting

Start with the [learning path](docs/LEARNING_PATH.md), [capability guide](docs/CAPABILITIES.md),
and the guide for the command or runtime area involved. BMEC 0.9.1-beta.1 is a
prerelease; a feature's support depends on the documented target and runtime
boundary.

For a useful issue, include:

- BMEC package and language versions
- Operating system, architecture, and Node.js version
- The smallest source example and exact command that reproduces the issue
- The diagnostic code and relevant output, with personal paths replaced
- Whether it reproduces after a clean install

Remove credentials, tokens, private URLs, customer records, database files,
personal paths, and other sensitive data before sharing logs. Do not include
secrets in public issues. For vulnerabilities, follow [SECURITY.md](SECURITY.md)
and use its private reporting route.
